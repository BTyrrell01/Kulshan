# Kulshan
Kulshan is an ESP32 based smart watch.

## Overview
As a lifelong endurance athlete, I have yet to find a watch that satisfies all of my desires. This watch is my attempt to do so. At its core the watch has an ESP32, with heart rate, SPO2 and HRV monitoring. GPS is also a core component, along with an altimeter/barometer and temperature sensor. The display is MIP for improved battery life.
